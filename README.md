# AFK LPC Hero Game

**AFK LPC Hero Game** is a 2D side‑scrolling idle RPG where you collect and upgrade heroes who automatically battle enemies. Each hero has unique abilities and skills, and progression continues even while you’re offline.

The game is built around the [Universal LPC Spritesheet Character Generator](https://github.com/liberatedpixelcup/Universal-LPC-Spritesheet-Character-Generator) and its web version ([Character Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/)). Use these tools and assets to generate, customize, and export hero sprites, then import them as heroes, equipment variants, enemies, and other 2D game assets.

## Features

- Collect and upgrade a wide roster of heroes.
- Fully automatic battles with minimal player input.
- Unique abilities and skills for every hero.
- Offline progression so you keep advancing when not playing.
- Strategic team composition to maximize battle effectiveness.
- Side‑scrolling idle gameplay with clean, LPC‑style 2D graphics.

## Development Plan

- Define JSON schemas and data files for all game entities (heroes, abilities, levels, items, enemies, etc.).
- Outline the game’s story, world, and setting.
- Specify the core gameplay loop and key mechanics.
- Design and implement diverse heroes with distinct abilities and skill sets.
- Build side‑scrolling exploration and stage mechanics.
- Implement the automatic battle system and AI behavior.
- Create hero upgrade and progression systems (stats, skills, gear).

- Optimize rendering and asset pipelines for smooth 2D visuals.
- Playtest, tune, and balance for an engaging long‑term experience.

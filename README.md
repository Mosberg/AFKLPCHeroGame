# AFK LPC Hero Game

2D side-scrolling idle RPG built around LPC-style sprites. Collect heroes, auto-battle enemies, and progress even while offline.

## Setup

1. Clone the repo.
2. Add LPC-generated sprites to `src/assets/heroes/` and `src/assets/enemies/`.
3. Open `index.html` in a browser (or serve via a local server).

## Features

- Hero collection and upgrades
- Automatic battles
- Offline gold accumulation
- Stage progression
